# Замер скорости скачивания

Консольный скрипт, который делает несколько последовательных GET-запросов к одному адресу, скачивает ответ полностью и печатает среднее время, объём данных и скорость скачивания. Есть две одинаковые по логике версии: на Python и на Node.js. Для Python есть дополнительно веб-интерфейс на Streamlit.

```
Speedtest/
├── README.md
├── python/
│   ├── speedtest.py        # консольный замер
│   ├── streamlit_app.py    # веб-интерфейс (необязательно)
│   └── requirements.txt
└── node/
    ├── speedtest.mjs       # консольный замер
    └── package.json
```

## Как это работает

- Запросы выполняются **строго последовательно**: следующий начинается только после того, как предыдущий скачан полностью.
- Каждый ответ читается до конца потоком, поэтому большой файл не загружается в память целиком.
- Время запроса измеряется от отправки запроса до получения последнего байта тела ответа.
- Запросы отправляются с заголовком `Cache-Control: no-cache`.
- Ошибки (HTTP-статус не 2xx, таймаут, недоступный хост) выводятся в консоль и попадают в CSV. В статистику такие запросы не входят.

## Требования

- **Python:** 3.9 или новее. Для Streamlit-версии нужны пакеты из `requirements.txt`.
- **Node.js:** 18.3 или новее. Внешних зависимостей нет.

## Установка

### Python

```bash
cd python
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Для одного только консольного скрипта достаточно `pip install requests`.

### Node.js

```bash
cd node
node --version                   # должно быть v18.3 или новее
```

Установка не нужна: скрипт использует только встроенные модули.

## Запуск

### Консольный скрипт (Python)

```bash
python python/speedtest.py https://example.com/big.jpg
python python/speedtest.py https://example.com/big.jpg -n 5 --csv results.csv
```

### Консольный скрипт (Node.js)

```bash
node node/speedtest.mjs https://example.com/big.jpg
node node/speedtest.mjs https://example.com/big.jpg -n 5 --csv results.csv
```

### Веб-интерфейс (Streamlit)

```bash
cd python
streamlit run streamlit_app.py
```

Откроется страница с полями: адрес, количество запросов и таймаут. После нажатия «Запустить» появятся метрики, таблица по запросам и кнопка «Скачать CSV».

## Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `<URL>` | Адрес, который нужно скачать. Должен начинаться с `http://` или `https://`. | — (обязательный) |
| `-n`, `--requests` | Количество последовательных запросов, целое число от 1. | `10` |
| `--timeout` | Таймаут одного запроса в секундах, включая скачивание тела ответа. | `30` |
| `--csv <файл>` | Сохранить результаты в CSV-файл. | не сохранять |
| `-h`, `--help` | Показать справку. | — |

Код возврата: `0`, если хотя бы один запрос успешен; `1`, если все запросы завершились ошибкой. При неверных параметрах Node.js возвращает `1`, а Python — `2` (стандартное поведение argparse).

## Единицы измерения

| Величина | Единица | Комментарий |
|---|---|---|
| Время запроса | миллисекунды (мс) | Среднее, минимум, максимум и медиана по успешным запросам. |
| Объём данных | МБ | 1 МБ = 1 048 576 байт (2²⁰). |
| Скорость | Мбит/с | 1 Мбит/с = 1 000 000 бит в секунду (как у провайдеров). |

Средняя скорость считается как **суммарный объём × 8 / суммарное время** по успешным запросам, а не как среднее арифметическое скоростей отдельных запросов. Так медленные запросы не получают искусственно завышенный вес.

Скорость в строках таблицы и в CSV считается по каждому запросу отдельно.

## Формат CSV

Файл сохраняется в кодировке UTF-8 с BOM, чтобы Excel правильно открывал русские заголовки. Разделитель — точка с запятой (`;`).

Первая таблица — результаты по каждому запросу:

```
№;статус;время, мс;объём, байт;скорость, Мбит/с;ошибка
1;ok;77.4;20971520;2166.3;
2;ошибка;;;;HTTP 404
```

Затем пустая строка и таблица с итогами:

```
показатель;значение
Запросов;10
Успешных;10
Среднее время, мс;35.7
Минимум, мс;20.4
Максимум, мс;77.4
Медиана, мс;31.7
Скачано, байт;209715200
Средняя скорость, Мбит/с;4705.3
```

Десятичный разделитель — точка. Если Excel с русской локалью показывает числа как текст, используйте «Данные → Из текста/CSV» и укажите разделитель `;` и десятичную точку.

## Ограничения

- **Кэш и CDN.** Заголовок `Cache-Control: no-cache` просят промежуточные кэши не отдавать сохранённую копию, но не все CDN и провайдеры его соблюдают. Тогда повторные запросы могут быть быстрее реальных. Чтобы увидеть реальную скорость, сравнивайте результаты с разных времён суток и с разных адресов.
- **Скорость сети локальной машины.** Результат зависит не только от канала, но и от загрузки процессора, антивируса, VPN и самого сервера.
- **Таймаут — общий на запрос.** Он включает установку соединения и скачивание всего тела. В Python таймаут дополнительно проверяется при чтении каждого блока, поэтому поведение совпадает с Node.js.
- **Последовательность.** Запросы не параллельные, поэтому тест измеряет скорость одного соединения, а не суммарную пропускную способность канала.
- **Редиректы.** Python следует за редиректами автоматически. Node.js `fetch` тоже следует за ними по умолчанию.
